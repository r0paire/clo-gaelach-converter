# Clo-gaelach-converter (Cló Gaelach Converter)
A Python application (with Tkinter for GUI) to convert modern Irish text for display in the Cló Ghaelach font type.
<br>
<br>
<h3>It has three modes: </h3>
• Classic (séimhiú and traditional letter styles)<br>
• Simplified (séimhiú and more modern letter styles),<br>
• and Rómhánach (Cló Rómhánach / Roman type used in modern Irish, no shéimiú - but in the style of Cló Gaelach).
<br>
<br>
<h2>Requirements:</h2>
• Python (tested on 3.12 & 3.14)<br>
• Tkinter (included in Python)<br>
• <a href="https://github.com/r0paire/clo-gaelach-converter/blob/7d2adea4316f22f21c0a659429507449551cafee/gaeilge.ttf"> gaeilge.ttf</a> (included in this repo)
